NURBS Surface Modeller

← All projects

Project 10 is a 3D NURBS surface modelling and CAM prep tool. Create curves, generate surfaces by loft or extrusion, build solid or shell bodies, then compute a zig-zag toolpath on the mesh and export G-code — matching the workflow of the original PyQt desktop application.

Author: ME23B036 NIRANJAN M Original: Python / PyQt5 + PyVista desktop app

Quick start

  1. Navigate: Left-drag to rotate, scroll to zoom, right-drag to pan.
  2. Curves: A default arch is loaded. Pick a curve in the list or click Create Curve.
  3. Edit points: Drag control points in the viewport. Shift+click the floor plane to add a point — no mode switch needed.
  4. Surface: Source → Extrude Active Curve → Generate Surface.
  5. Solid body: Mode → Full Solid Extrusion → Extrude Selected Surface.
  6. Toolpath: Source → Derived Body Mesh → Generate Zig-Zag Toolpath.
  7. Export: Open G-code Export → Export G-code.

Example — arch profile → solid → toolpath

On load you already see Curve 1 (a Bezier arch on the XY plane). Follow these exact settings to reproduce the demo from the original Python app:

  1. Curves — leave Curve 1 (Bezier) selected. Optional: drag handles or Shift+click the plane to tweak the arch.
  2. Surface Generation — Source: Extrude Active Curve · Axis: Z+ · Height: 40 · Layers: 3 · Samples: 30 → click Generate Surface.
    You should see a light-blue surface sheet rising along Z.
  3. Surface Operations — Mode: Full Solid Extrusion · Distance: 40 → click Extrude Selected Surface.
    A teal solid block appears around the surface.
  4. Toolpath — Source: Derived Body Mesh · Stepover: 1 · Tool radius: 2 → click Generate Zig-Zag Toolpath.
    Green zig-zag lines appear on the solid.
  5. G-code Export — open that section → click Export G-code to download toolpath.nc.
